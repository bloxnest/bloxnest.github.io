A few quick answers.

How do I open multiple Roblox windows?

BloxNest is a Roblox multi-instance tool: pick how many windows, press Start, and log into a different account in each. If Roblox is already open, it closes those windows first after asking you.

Can I get banned?

BloxNest doesn't modify Roblox or inject anything, but it isn't made or approved by Roblox, so nobody can promise anything. Use it at your own risk.

Is BloxNest free?

Yes. It's source available: you can read the code on GitHub, but not republish it.

Why does Windows show a warning?

BloxNest isn't code-signed yet, so Windows may say "Windows protected your PC". If you downloaded it from this site or GitHub, choose More info, then Run anyway.

Does it modify Roblox?

No. It opens Roblox normally and stops Roblox's one-window check from closing the extra windows. If your Roblox is out of date, it runs Roblox's own updater first.
