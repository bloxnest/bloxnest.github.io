How it works

Three steps. You're in.

You handle your accounts. BloxNest opens the windows.

    Pick how many windows

    Choose 1 to 5 in one click, or type a number up to 20.

  2. 02

    Hit Start

    Log in and play side by side

    Use a different account in each window.

Good to know

A few quick answers.

The practical stuff, including what BloxNest does and what nobody can promise.

How do I open multiple Roblox windows? +

Download BloxNest, pick a number of windows, and press Start. Use a different Roblox account in each window.

Can I get banned? +

BloxNest doesn't modify Roblox or inject anything, but it isn't made or approved by Roblox. Nobody can promise you won't be banned. Use it at your own risk.

Is BloxNest free? +

Yes, BloxNest is free to use. Its code is source available under the PolyForm Strict License 1.0.0: you can read the code and use the app, but you can't redistribute it or publish modified versions.

Does it modify Roblox? +

No. BloxNest doesn't change Roblox's files or inject into the game. It opens Roblox normally and stops the "only one window" check from closing the extra windows. If Roblox is outdated, it runs Roblox's own updater first.

How many windows can I open? +

Up to 20 windows. Each window uses memory, so start with a few.
